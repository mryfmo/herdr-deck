## Objective

出荷状態で壊れているビルド/検証基盤を最小 diff で修復し、`make validate` が素の macOS(swift-format は xcrun 経由のみ、PyYAML なし、gateway/config.json 存在)で成立する状態にする。

## 修正内容(すべて必須)

### 1. C-2: iOS/HerdDeck/Services/NetworkPathService.swift

`private static func interface(for path: NWPath)` を `nonisolated` にする(状態非依存の純関数)。他の変更は不可。
理由: nonisolated な `monitor.pathUpdateHandler` 閉包から @MainActor 分離メソッドを同期呼び出ししており Swift 6 でコンパイルエラー。

### 2. C-3: iOS/HerdDeck/Features/Console/MoshSessionController.swift:160

`session?.resize(columns: Int32(columns), rows: Int32(rows))` → `session?.resize(withColumns: Int32(columns), rows: Int32(rows))`。
理由: ObjC `- (void)resizeWithColumns:rows:` は Swift へ `resize(withColumns:rows:)` として import される。ヘッダ側の変更(NS_SWIFT_NAME)は行わない。

### 3. C-6: scripts/bootstrap-mac.sh

17-29 行の `cat <<MSG` heredoc 内、25 行目のバッククォート `` `claude` `` と `` `codex` `` がコマンド置換として実行される。バッククォートを ` \`` でエスケープする(最小 diff)。 `$CONFIG` の展開は維持すること。

### 4. Makefile(H-B1, H-B2, M-B1, bash -n)

- `data-validate` の `@for f in scripts/*.sh; do bash -n "$$f"; done` → 各失敗で即 exit するよう `|| exit 1` を追加
- `@swift-format lint --recursive iOS` → `command -v xcrun` があれば `xcrun swift-format lint --recursive iOS`、なければ従来コマンドへフォールバック
- `@python3 -c 'import pathlib,yaml; ...'` → PyYAML が import 可能な場合のみ実行し、不可なら「skipping project yml validation (PyYAML not installed)」を表示してエラーにしない(1 行の shell 条件で簡潔に)
- `validate` から `@test ! -f gateway/config.json` と secret ファイル find の 2 assert を除去し、新 target `dist-validate`(.PHONY 追加)へ移す。`validate: check data-validate package-validate` は維持
