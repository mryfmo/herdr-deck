# T006 — Phase 2 (iOS): ターミナル入力・契約・安定性修正

Repo: /Users/mryfmo/Workspace/HerdDeck-0.2.0
背景: 監査計画書の H-I1, H-I2, M-I1, M-I2, M-I3, M-I4。

## 修正内容(すべて必須)

### 1. H-I1: `iOS/HerdDeck/Features/Console/TerminalInputMapper.swift`

未知の `ESC [` / `ESC O` シーケンス(mouse reporting、application cursor、bracketed paste 等)を「esc キー + 残骸テキスト」に分解せず、シーケンス全体を破棄する。既知シーケンス(現行の CSI A/B/C/D/Z)のマップは維持。lone ESC(後続なし)は従来どおり `esc`。

### 2. H-I1 続: `iOS/HerdDeck/Features/Console/TerminalEmulatorView.swift`

gateway ルートでは mouse reporting を無効化する(Mosh ルートは現状維持)。ルート情報の受け渡しは最小の変更で。

### 3. H-I2: gateway ルートの送信を順序保存・分割送信へ

`TerminalInputMapper` の出力を「text と keys の交互順序を保存した chunk 列」に変え、呼び出し側(TerminalConsoleView / AppState の送信経路)は chunk ごとに `/v1/herdr/panes/:id/input` を逐次 await 送信する。1 chunk の keys は 32 個以下に自然に収まる分割であること。複数行ペーストが丸ごと 400 拒否されないこと。

### 4. M-I1: `iOS/HerdDeck/Models/MissionModels.swift`

`AgentStartedResponse` を gateway が実際に保証する形へ緩和: `argv` を optional に、agent は `paneId`/`terminalId` のみ必須の slim struct でデコード(既存 HerdrAgent への依存を外す)。呼び出し側の使用フィールドを確認して追随。

### 5. M-I2: `iOS/HerdDeckMosh/HerdMoshSession.mm`

resize で `_windowSize` 更新後に mosh スレッドへ SIGWINCH を送る(`pthread_kill(_moshThread, SIGWINCH)` 相当。スレッドハンドルを start 時に保持)。`_windowSize` の読み書きを同一ロックで保護。ヘッダ変更が必要なら `iOS/HerdDeckMosh/HerdMoshSession.h` も可。

### 6. M-I3: `iOS/HerdDeck/App/AppState.swift`

`updateTerminalPreferences` は `transportPolicy` が変わった場合のみ `transportSwitchTask?.cancel()` + 即時 recompute。表示モード等の変更では hysteresis を維持。

### 7. M-I4: `iOS/HerdDeck/Services/AgentNotificationService.swift`

`Dictionary(uniqueKeysWithValues:)` → `Dictionary(_:uniquingKeysWith:)`(後勝ち)。
