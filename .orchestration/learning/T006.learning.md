# T006 Learning Triage

## Candidate

When translating terminal bytes into a higher-level input API, an unsupported escape sequence must be consumed as one bounded sequence. Mapping only its ESC prefix leaks the remaining control bytes as user text and can corrupt the remote TUI.

## Evidence

The standalone check proves mouse, SS3 application-cursor, and bracketed-paste wrappers are fully consumed while known CSI keys and lone ESC retain their existing meanings.

## Disposition

Candidate only. No reusable rule or skill was promoted by this worker.
