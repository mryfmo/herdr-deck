# T005 Gateway Stability Report

## Verdict

READY FOR REVIEW. All requested gateway fixes and socket-independent regression tests are complete.

## Changes

- Snapshot fingerprints omit output-volatile `pane.scroll`, pane `revision`, and agent `revision`, while retained fields still detect topology and agent-state changes.
- Gateway startup converts persisted `starting` missions to `failed` with `gateway restarted during start` and publishes each mission transition before resuming `running` missions.
- `/v1/*` rate limiting now runs before bearer authorization and uses only the source address as its key; `/healthz` remains unauthenticated and unlimited.
- `HerdrRpcError` maps `not_found`/`*_not_found` to 404, `invalid_*` to 400, and all other Herdr RPC failures to 502. Error envelope codes are always strings.
- Stored Mosh session metadata expires after ten minutes through an unreferenced delayed deletion.
- Added focused coverage for router security/error behavior, stale mission recovery, snapshot scroll suppression, Mosh session expiry, and the previously untested `MissionOrchestrator.start` happy path.
