# T004 iOS SSE Parser Report

## Verdict

READY FOR REVIEW. SSE framing now dispatches on byte-level blank-line boundaries, parser state is bounded, and the AppState reconnect task no longer retains the owner for the loop lifetime.

## Changes

- Added internal `SSEFrameParser` to `GatewayClient.swift`.
- Replaced `bytes.lines` with byte-by-byte `URLSession.AsyncBytes` feeding.
- Supports LF/CRLF, `event:` fields, multiline `data:` joining, comments/unknown fields, consecutive events, and default `message` names.
- Caps one line at 256 KiB and accumulated event data at 1 MiB; an oversized event is discarded and parsing resumes after its blank boundary.
- Leaves unterminated stream-tail state undispatched.
- Changed AppState to promote weak `self` only for individual event handling/status updates.
- Resets SSE retry delay to one second whenever an event is received.
