# T006 iOS Terminal Stability Report

## Verdict

READY FOR REVIEW. All requested terminal input, response-contract, transport, Mosh resize, hysteresis, and notification fixes are implemented.

## Changes

- `TerminalInputMapper.map` now returns ordered chunks. Text and key runs remain in their original order, and consecutive key chunks cap at 32 entries.
- Known CSI arrow/shift-tab mappings remain intact. Unknown CSI/SS3 sequences are discarded through their terminator; lone ESC remains `esc`. Bracketed-paste wrappers are removed while their contents are preserved.
- Gateway terminal input sends each mapped chunk sequentially with `await`.
- SwiftTerm mouse reporting is enabled only for the Mosh terminal route and disabled for the Gateway route.
- `AgentStartedResponse` now decodes a slim `StartedAgent` containing only `paneId` and `terminalId`; `argv` is optional. Existing callers only use `paneId`.
- Mosh records its engine `pthread_t`, updates the active window size under the same lock, then sends SIGWINCH on resize.
- Terminal preference updates cancel hysteresis and recompute routing only when `transportPolicy` changes.
- Notification status snapshots now tolerate duplicate terminal IDs and keep the last value.
- Model decoding coverage now includes ordered mapper chunks, unknown sequence suppression, 33-key splitting, and the slim start response.
